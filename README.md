# Digital Business Card - Ready for Vercel

This is a ready-to-deploy React + Vite project for a digital business card generator.

## How to run locally

```bash
npm install
npm run dev
```

## How to deploy on Vercel

1. Upload this project to a GitHub repository.
2. Go to https://vercel.com
3. Click **Add New Project**
4. Import the GitHub repository
5. Click **Deploy**

## Features

- Digital business card generator
- Shareable hash-based link
- QR code generation
- Download contact as `.vcf`
- Theme selection
- Public card view
