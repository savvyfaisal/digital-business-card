# Digital Business Card - Corrected V2

This is a corrected Vercel-ready React + Vite project.

## Deploy steps
1. Extract this ZIP.
2. Upload all files to a GitHub repository.
3. Import the repository in Vercel.
4. Framework preset: **Vite**.
5. Build command: **npm run build**.
6. Output directory: **dist**.

## Project structure
- package.json
- vite.config.js
- index.html
- vercel.json
- src/App.jsx
- src/main.jsx
- src/styles.css
